# Experiment 008: 框架状态向量升级

## 这不是删选股规则

第 007 轮“只保留有同题材梯队的股票”被否定：它把一个重要事实误写成硬门槛，可能过滤掉单点破局和独立核心。本轮不测试新的买卖规则，而是修复进化基础设施，让后续 Challenger 能真正修改环境、情绪、节点和候选池理解。

## 当前 Champion 暴露的问题

原始案例把复杂判断压成一个环境标签，再用板位、封单额和封板时间排序。这样无法回答：

- 指数上涨但情绪仍在退潮时，为什么还允许进攻？
- 情绪修复是跌停减少、连板溢价恢复，还是只是指数反弹？
- 一个三板票是主线核心、补涨、卡位，还是孤立公告刺激？
- 候选是题材前排，还是只是全市场板位排序靠前？

## 本轮实现

在 `scripts/generate_month_cases.py` 中补充盘后可见的事实字段：

- 环境轴：指数方向、三指数共振/分化。
- 情绪轴：涨跌停差、风险压力、炸板率、最高板。
- 主线轴：题材涨停数量、题材最高板、候选在题材内的位置。
- 节点事实：市场最高板、题材前排、低位题材参与、炸板/分歧等可观察事实。

这些字段是事实记录，不是假装已经理解了“穿越、破局、补涨、卡位”。历史节点仍需下一轮补齐连续日序列。

## 诊断结果

基于同一版结构化案例和同一代理结果：

- `进攻/修复` 环境下，60 个竞价可做候选的收益合计为 `-104.42%`；但逐日最佳机会平均为 `+1.09%`。
- 这表明环境标签并非完全没有信息，主要问题是没有把环境与节点适配、候选排序连接起来。
- “情绪修复”转移阶段的可做候选合计为 `-117.27%`，说明当前情绪修复定义过于粗糙，可能只是指数或涨停数量修复，并未确认中位股和高位核心的负反馈结束。
- 同样的三指数共振也不能直接等同于短线接力环境：该分组的候选收益仍明显分化。

## 结论

本轮不产生生产 Challenger，不修改 `SKILL.md`。它完成的是进化对象从“一个标签 + 一个排序”升级为状态向量，为下一轮真正改环境定义提供数据基础。

下一轮只改一个框架假设：把“情绪修复”拆成“指数修复”和“接力情绪修复”，后者必须有中位股/高位核心负反馈收敛的盘后证据；先做训练集和时间外验证，再决定是否进入 Skill。
